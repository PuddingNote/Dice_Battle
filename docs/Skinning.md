# UI 스킨(스프라이트) 적용 가이드

현재 UI는 코드로 생성되지만, **스프라이트를 꽂으면 로직 수정 없이 실제 게임 룩**으로 바뀌도록
스킨(Skin) 시스템을 두었다. 스프라이트를 지정하지 않으면 지금의 단색 UI로 동작한다.

## 1. 스킨 에셋 만들기
1. Unity Project 창에서 우클릭 → **Create → DiceBattle → UI Skin**
2. 생성된 `UiSkin` 에셋을 원하는 폴더(예: `Assets/Art/`)에 둔다.

## 2. 부트스트랩에 연결
- 씬의 `GameBootstrap` 컴포넌트(게임 오브젝트)에 있는 **Skin** 슬롯에
  방금 만든 UiSkin 에셋을 드래그해 연결한다.
- 비워 두면 기본 단색 UI로 실행된다.

## 3. 슬롯 설명 (모두 선택 사항 — 비우면 해당 요소는 단색 폴백)
| 슬롯 | 대상 | 비고 |
|------|------|------|
| Font | 모든 텍스트 폰트 | 미지정 시 내장 폰트 |
| Screen Background | 전체 배경(메뉴/보드) | 전체 화면 |
| Field Panel | 내/상대 필드 패널 프레임 | 색으로 구분(틴트) → 9-slice 권장 |
| Center Panel | 중앙(상태/획득 주사위) 패널 | 9-slice 권장 |
| Line Normal / Line Highlight | 라인 행 배경 / 선택 강조 | 9-slice 권장 |
| Cell Empty / Cell Filled / Cell Special | 빈 칸 / 채운 칸 / 특수 칸 배경 | 9-slice 권장 |
| **Dice Faces (6)** | 주사위 눈 1~6 | **6개 모두 지정 시 숫자 대신 스프라이트 표시.** 배열 index 0=눈1 … 5=눈6 |
| Button | 모든 버튼 배경 | 9-slice 권장 |

## 4. 동작 규칙
- 스프라이트가 지정된 슬롯은 해당 이미지로, 색상은 **틴트**로 적용된다(필드의 파랑/빨강 구분 유지).
- 특수 주사위는 `Cell Special` 스프라이트가 있으면 그걸로, 없으면 금색 테두리로 표시.
- 주사위 눈은 `Dice Faces`에 6개를 모두 채워야 스프라이트로 바뀐다(하나라도 비면 숫자 사용).

## 5. 색상/치수만 바꾸고 싶다면
- 색상/폰트 크기/셀 크기 등 기본값은 `Assets/Scripts/UI/UiTheme.cs` 상수에서 조정.

## 참고 (향후)
- 더 정교한 아트/애니메이션이 필요하면 이 스킨 구조를 유지한 채
  프리팹 기반 뷰로 확장하거나 TextMeshPro로 전환할 수 있다.
